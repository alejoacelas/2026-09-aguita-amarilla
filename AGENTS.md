# Mi agüita amarilla

Explores whether Claude Code can one-shot a new music video for "Mi agüita
amarilla" (Los Toreros Muertos) in the crude, mouse-drawn MS Paint style of a
2010 fan video.

- `prompt.md` is the one-shot prompt. Run it from the repository root.
- `reference/style.md` and the four drawings in `reference/frames/` are style
  hints. The scenes come from the lyrics.
- `reference/video.mp4` is the original fan video. Don't watch it during the
  remake, so the drawings come from the lyrics rather than copying the original.
- `reference/video.mp4` and `reference/song.mp3` are copyrighted and ignored.
  Rebuild them as described in the README.
- Put renders in `out/` (ignored).
